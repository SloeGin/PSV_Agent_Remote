# PSV Agent Remote: Vita app

The PS Vita side of PSV Agent Remote, written in C with VitaSDK and libvita2d. See the [main README](../README.md) for what it does and how to set it up.

## Build

Requires VitaSDK in `~/vitasdk` with these packages installed through `vdpm`: `libvita2d freetype libpng zlib libjpeg-turbo bzip2 mbedtls`.

```bash
export VITASDK=$HOME/vitasdk PATH=$HOME/vitasdk/bin:$PATH
cmake -S vita -B vita/build -DCMAKE_POLICY_VERSION_MINIMUM=3.5
cmake --build vita/build        # produces vita/build/psv_agent_remote.vpk
```

## Tests

The platform-independent code (protocol, model, layout, Markdown, input mapping, config, PSK parsing) builds with the host compiler under ASan and UBSan, so no SDK is needed:

```bash
make -C vita/tests                                        # prints ALL PASS when every test passes
make -C vita/tests mqtt_smoke && vita/tests/mqtt_smoke    # talks to a real broker (MQTT_HOST)
```

## Files on the Vita

Everything lives in `ux0:data/psv_agent_remote/`:

- `config.txt`: settings and the broker list, also editable from the Settings page (START). A plaintext broker is written `broker=IP[:port]` (port 1883 by default), an encrypted one `broker=tls://IP[:port]` (port 8883 by default).
- `psk.txt`: the pre-shared key for `tls://` brokers, one line `<identity>:<64 hex digits>`, created by `tools/psk_pair.py`.

Versions before the rename used `ux0:data/psv_claude_remote/`; the app moves that folder on first start.

## Source layout

| File | Responsibility |
|---|---|
| `main.c` | Main loop, input routing, system dialogs |
| `net.c`, `mqtt_client.c`, `outbox.c`, `reconnect.c` | Network thread, MQTT 3.1.1 client with optional TLS-PSK, delivery and reconnect |
| `protocol.c`, `model.c` | Message parsing and the session/request model |
| `ui.c`, `gfx.c`, `textlayout.c`, `markdown.c`, `view.c` | Drawing, fonts, text wrapping, Markdown, scrolling and tables |
| `input.c`, `settings.c`, `sessionlist.c` | Buttons, sticks and touch; the Settings page; the session list |
| `config.c`, `psk.c`, `util.c`, `audio.c` | Config file, key file, UTF-8 helpers, chimes |

## Fonts and artwork

- `assets/font.otf`: a Noto Sans SC subset (GB2312 + ASCII) for CJK text, generated by `tools/subset_font.py`.
- `assets/mono*.ttf` and `assets/sans*.ttf`: Latin subsets of JetBrains Mono and Space Grotesk, generated by `tools/latin_fonts.py`.
- Licenses: `assets/OFL-*.txt` (SIL Open Font License).
- Icon and LiveArea art: `python3 tools/make_livearea.py vita/sce_sys vita/assets` (needs Pillow).

The UI mockup is at [docs/mockup/index.html](../docs/mockup/index.html).
